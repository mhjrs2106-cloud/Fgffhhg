SOUTH LIFE RP — Website package

Files:
- index.html: Home page
- apply.html: Management application form (formats and copies the application; it does not send data automatically)
- rules.html: Admin rules page
- styles.css: Responsive black/yellow design
- script.js: Application form behavior
- assets/logo.png: Your provided server logo

How to use:
1. Extract the ZIP.
2. Upload all files and the assets folder to a static website host (for example Cloudflare Pages).
3. Keep the three HTML files in the same folder and preserve the assets folder.
4. The Discord invite is set to https://discord.gg/QUrHxS59Yv.
5. The source list did not include rule 29, so numbering is preserved as supplied.

Note: This is a static site. The application form does not store submissions or automatically send them to Discord; it creates formatted text for the applicant to copy and send. Automatic submission requires a secure backend or Discord bot.
